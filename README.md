# C# OOP Fundamentals 🚀

[TR] Bu depo, C# dilinde Nesne Yönelimli Programlama (OOP) prensiplerini pekiştirmek ve BTK Akademi C# eğitimi sürecindeki kod pratiklerini saklamak amacıyla oluşturulmuştur.

[EN] This repository is created to reinforce Object-Oriented Programming (OOP) concepts in C# and to store code practices developed during the BTK Academy C# training course.

---

## 📌 İçerik ve Mimari / Content & Architecture

### TR - Türkçe
- **Sınıf (Class) ve Nesne (Object) Mantığı:** Nesne tabanlı düşünme ve şablon oluşturma.
- **Kalıtım (Inheritance):** `Calisan` ana sınıfından `Yazilimci` sınıfına özellik aktarımı (`Yazilimci : Calisan`).
- **Kapsülleme (Encapsulation):** `Maas` özelliği için `private` değişken ve `get`/`set` blokları ile asgari ücret denetimi.

### EN - English
- **Class & Object Concepts:** Object-oriented mindset and template design.
- **Inheritance:** Deriving the `Yazilimci` (Developer) class from the base `Calisan` (Employee) class (`Yazilimci : Calisan`).
- **Encapsulation:** Protecting data using a `private` backing field for `Maas` (Salary) with `get`/`set` validation logic for minimum wage control.
